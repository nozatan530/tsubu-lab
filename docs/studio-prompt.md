## 何を作るか
高校化学基礎の「質量パーセント濃度」「物質量（モル）」「モル濃度」を、粒と箱の操作で体験しながら理解するアプリです。
計算ドリルではなく、「予想する → 操作して確かめる → 粒・図・式の3つの見方で見比べる」ことが主役です。
利用者は高校生で、授業中に一人1台の端末で取り組みます（家庭での復習にも使えます）。
端末は Chromebook・iPad・スマホが混在します。

## 学びのねらい（アプリ全体で一貫させること）
- 「量」（溶質の質量・物質量・溶液の量）と「割合」（濃度）を区別できる。溶液を分けても濃度は変わらない、水を足すと濃度が下がる、を粒の見た目で示す
- 質量パーセント濃度の分母は「溶液全体（溶質＋水）」であって「水」ではない
- モルは「6.02×10²³個をひとまとめにした1パック」。1パックの重さ（モル質量）は物質によって違う
- モル濃度は「溶液1Lあたり何パック」。「水1Lに溶かす」と「溶液全体を1Lにする」は違う
- 公式の ÷・× が、粒やパックの操作を文字で書いたものだとわかる
- 用語には言い換えを併記する：物質量（パック数）、モル質量（1パックの重さ）、モル濃度（1Lあたりのパック数）

## 3つの単元と、粒・箱の約束
どの単元も同じ見た目のルールで描きます。いま使っている約束（縮尺）は、操作エリアの隅に常に小さく表示してください。

### ① 質量パーセント濃度
- ビーカーの中に、溶質を「粒」（1粒＝1g）で描く。水は水色の液面の高さで描く（粒にしない）
- 横にてんびん風の表示で「溶質 ○g／水 ○g／溶液 ○g」を出す
- 操作ボタン：溶質を足す（+1g・+5g）／水を足す（+10g・+50g）／溶液をくみ出す（半分・1/4 など、くみ出した分は別のビーカーに移る）／2つのビーカーを混ぜる
- 溶液を分けたとき、どちらのビーカーも「粒の混み具合」が同じに見えるようにする（濃度は同じ）
- 溶質は最大50g程度、溶液は最大300g程度に収め、粒が描ききれなくならないようにする

### ② 物質量（モル）
- 粒を「パック」（箱のアイコン）にまとめて描く。1パック＝6.02×10²³個
- 0.1パック単位を扱えるよう、1パックを10ピースに分けた絵にする（例：0.3mol＝3ピース）
- 物質を選ぶと、1パックの重さ（モル質量）が変わる。ミカン1箱とスイカ1箱では同じ「1箱」でも重さが違う、というたとえを最初に1回だけ見せる
- 操作ボタン：物質を選ぶ／パックを増減（±1・±0.1）／重さ（g）を入力してパック数を求める
- 表示：パック数（mol）・粒の個数（○×10²³個）・重さ（g）を同時に出す
- 原子量は H=1.0、C=12、O=16、Na=23、Cl=35.5 を使う
  （H₂O=18、CO₂=44、NaCl=58.5、C₆H₁₂O₆=180、O₂=32）

### ③ モル濃度
- 目盛り付きの容器（メスフラスコ風）の中にパックを描く。液面の高さと「溶液全体の体積（mL）」を表示する
- 操作ボタン：パックを入れる（±0.1・±1）／水を足す（+10mL・+100mL）／標線（100mL・500mL・1L から選ぶ）まで水を合わせる／一部をくみ出す
- 溶質を入れると溶液の体積がわずかに増えるように表示する（例：NaCl 1パックで約+20mL。「説明用の目安」と注記する）。これにより「水1Lに1パック入れても、ちょうど1mol/Lにはならない」が見えるようにする
- 表示：パック数・溶液の体積・モル濃度（1Lあたりのパック数）

## 粒・図・式の切替（全画面共通の部品）
操作エリアの上に「粒」「図」「式」の3つの切替ボタンを置き、同じ状態を3つの見方で表示します。
- 粒：上記のビーカー・パック・容器の絵
- 図：線分図（帯）で、溶質と溶液、またはパック数と体積の関係を表す（「○gあたり」「1Lあたり」の図）
- 式：その状態を表す計算式を、実際の数字を入れて表示する
  例：10g ÷（10g＋90g）× 100 ＝ 10%
- 3つの見方で、同じ量には同じ色を使う（溶質＝オレンジ、水＝水色、溶液全体＝緑、のように）。式の数字にも色をつけ、粒や図のどの部分にあたるかが目で追えるようにする
- 結果画面では3つを横（狭い画面では縦）に並べて見せる

## 画面と操作

### 1. ホーム
- 単元マップ：①質量パーセント濃度 → ②物質量 → ③モル濃度 → 総合 の順につながった道として表示
- それぞれに獲得した星の数を表示。どの単元からでも始められる（ロックしない）
- 「カード帳」ボタン、「記録をすべて消す」ボタン（確認ダイアログあり）

### 2. 実験室（単元ごと）
- その単元のシミュレーターを自由に操作できる画面。ミッションなし
- 単元を初めて開いたときは、まず実験室を表示し、「さわってみよう」と30秒ほど自由に触ってからミッションに進む流れにする
- 「ミッションへ」ボタン

### 3. ミッション
- 流れ：お題 →「どうなると思う？」の予想（3〜4択）→ 操作 →「確かめる」ボタン → 結果
- 予想を選ぶまで操作エリアは押せない
- 数値で答えるミッションは、数字入力欄で答える（有効数字2〜3桁で、近い値なら正解とする）
- 手数（ボタンを押した回数）を数えて小さく表示する
- 各単元に4〜6問。ミッションの例：
  - ①「10%の食塩水100gを半分に分けると、濃度は？」（5%／10%／20%）
  - ①「水90gに食塩10gを溶かした。濃度は？」（10%／約11%）←分母は溶液全体
  - ①「5%の食塩水を200g作れ」（食塩と水の量を操作で決める）
  - ①「10%と20%の食塩水を100gずつ混ぜたら？」
  - ②「1パックが重いのは H₂O と NaCl のどっち？」
  - ②「H₂O 2パックは何g？」「36gの水は何パック？粒は何個？」
  - ②「CO₂ 0.5パックは何g？」
  - ③「水1Lに NaCl 1パックを入れた。濃度はちょうど1mol/L？」（ちょうど／少し小さい／少し大きい）
  - ③「NaCl 0.1パックで、0.1mol/L の溶液を作れ」（標線1Lまで水を合わせる）
  - ③「1.0mol/L の溶液100mLに水を足して、0.10mol/L にせよ」
  - 総合「0.10mol/L の NaCl 水溶液を500mL作れ。NaCl は何g必要？」（カードを使って g に換算）

### 4. 結果
- 星（最大3つ）：クリアで1つ、予想が当たったら+1、目標手数以内なら+1
- 予想と結果を並べて表示し、予想が外れたときは「なぜそうなるか」を粒の絵で1〜2文で説明する。責める言い方にしない
- 粒・図・式の3つを並べて表示
- 「もう一度」「次のミッション」「ホームへ」ボタン

### 5. カード帳（モル質量カード）
- ②の単元以降、ミッションで新しい物質が出てきたらカードを1枚獲得する（H₂O、O₂、CO₂、NaCl、C₆H₁₂O₆）
- カードには「物質名・化学式・1パックの重さ（g/mol）・原子量の内訳（例：H₂O＝1.0×2＋16）」を書く
- ②③のミッション中は、画面の端からカードを開いて参照できる。g⇔mol の換算はカードを見ながら行う

## データ
- 保存はブラウザの localStorage だけ。サーバーには一切送らない
- 保存するもの：クリアしたミッション、星の数、獲得したカード
- ログインなし。名前・出席番号・クラスは聞かない。自由記述欄も作らない
- localStorage が使えない場合でも、その場では遊べるようにする（エラーで止まらない）

## 見た目
- 高校生向け。理科の実験室らしい清潔で明るい色づかい。子どもっぽくしすぎない
- 横長（Chromebook）では「操作エリア」と「数値・切替」を左右に並べ、縦長（スマホ）では上下に積む。幅360pxでも崩れない
- 操作はすべてタップ（クリック）でできるようにする。ドラッグがないと進めない操作は作らない
- ボタンは指で押しやすい大きさ。数字は大きく見やすく
- 日本語UI。化学式の下付き数字（H₂O など）を正しく表示する
- 粒・パックの数が変わるときは、短いアニメーションで増減が見えるようにする

## 技術の条件
- サーバーなしで動く静的なWebアプリ（GitHub Pages で公開できること）
- Gemini API など外部AIの呼び出しは入れない
- APIキーをコードに書かない
- 外部ライブラリは最小限（粒や容器の絵は SVG か Canvas で自前で描く）
- 濃度・物質量の計算は1か所の関数にまとめ、表示と判定で同じ計算を使う
